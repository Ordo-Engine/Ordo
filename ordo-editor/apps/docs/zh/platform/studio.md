# Studio 编辑器

Studio 是 Ordo Platform 的可视化编辑器，运行在浏览器中。它为同一份规则集提供三种视图，视图之间实时同步。

![Studio 流程图视图中的贷款审批规则](/screens/zh/flow.webp)

## 三种编辑模式

### 流程图（Flow）

- 基于 Vue Flow 的蓝图风格画布。
- 节点类型：Decision（决策分支）、Action（赋值与外部调用）、Terminal（终结输出）、SubRule（子规则调用）。
- Pin 风格：三角形为执行流，圆形为数据流。
- 支持多入度：多个上游节点可以连到同一节点的输入端，重复连线会自动去除。
- 拖拽连线时会高亮兼容的目标 Pin；回放执行轨迹时，经过的节点会被着色。

### 表单（Form）

- 树形结构编辑器，适合不习惯流程图的业务用户。
- 每个步骤是一张卡片，子规则与决策分支自动嵌套。

### 决策表（Decision table）

- 把同一份规则集排成条件和结果的表格，每一行是规则里的一条路径。
- 显示命中策略，可以手动添加输入列和输出列，也可以从 Schema 导入。
- 规则集的分支能排成表格时可用，不能时 Studio 会提示。

![同一份规则在决策表视图中](/screens/zh/table.webp)

如果想直接编辑 RuleSet JSON，可以通过 [CLI](./cli) 处理规则文件。

三种模式共享同一份编辑状态。任一视图中的修改会立即反映到其他视图，并记入撤销历史。

## 执行追踪面板

发布前可以在 Studio 中输入一段 JSON 上下文并点击 **试运行**。平台调用 ordo-server 的 trace API，返回每一步的：

- 入口/出口快照
- 命中的分支条件
- 表达式求值过程
- 子规则调用堆栈
- 总耗时与每步耗时

追踪结果以 [ExecutionAnnotation](https://github.com/Ordo-Engine/Ordo) 浮窗显示在流程图节点上方。

## 测试用例集成

测试用例可以在 Studio 内编辑、单独运行或批量运行。结果按颜色区分：

- 绿：实际输出与期望一致
- 红：mismatch，会展开 diff
- 灰：尚未运行

![Studio 中的测试用例：期望结果与实际结果](/screens/zh/tests.webp)

详见[测试管理](./testing)。

## 模板与子规则

- **模板**：从 `Marketplace` 或内置模板库克隆出包含规则、契约、事实和测试用例的完整项目。
- **子规则资产**：在项目级抽取常用片段（如「KYC 审核」「风险评分」），在多个规则集中复用。

## 国际化

Studio 与文档支持英文、简体中文和繁体中文，UI 语言可在侧边栏底部切换。
