# Studio

Studio 是平台的编辑器，在浏览器里使用。同一个规则集有三种视图，在一个视图里改了，其他视图立刻同步。

![Studio 流程视图中的贷款审批规则集](/screens/zh/flow.webp)

## 视图

- 流程：步骤和连线组成的画布。判断、动作、终止、子规则步骤都是节点。
- 表单：每个步骤一张卡片，分支和子规则嵌套在里面。不习惯看图的人用起来更顺手。
- 表格：把规则集展开成一行行的条件和结果，每条路径一行。分支能排成表格时才可用，不能时 Studio 会提示。

![同一个规则集的表格视图](/screens/zh/table.webp)

要直接编辑 JSON，请通过[命令行](./cli)操作文件。

## 试运行

粘贴一个输入，点「运行」。Studio 用引擎执行草稿，显示走过的路径、每一步命中了哪个分支、子规则调用、结果和每一步的耗时。路径也会画在流程视图上。

## 测试

每个规则集都有测试用例：一个输入，加上期望的结果码和输出。可以单独跑一个，也可以全部跑。通过的显示绿色，失败的显示红色并附差异，没跑过的是灰色。

![Studio 中的测试用例，包含期望结果与实际结果](/screens/zh/tests.webp)

这些用例和命令行用的是同一份 `tests/<name>.json`，所以 `ordo pull` 能把它们拉进仓库，在 CI 里用 `ordo test` 跑。见[测试与影响](/zh/guide/testing)。

## 语言

Studio 支持英文、简体中文和繁体中文，在侧边栏底部切换。
